# Career Companion - Frontend Project Context

## Project Overview

Career Companion is a full-stack platform designed to help users manage and optimize their job search journey.

The platform combines:

1. Job Application Tracker
2. Interview Preparation Hub

The goal is to provide a single platform where users can:

- Track job applications
- Manage application statuses
- Store interview schedules
- Save resumes
- Organize interview questions
- Maintain preparation notes
- Save learning resources
- Monitor progress through analytics
